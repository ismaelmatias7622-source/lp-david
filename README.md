# IDEALIZA Contabilidade — Landing Page

Landing Page moderna, responsiva e de alta conversão desenvolvida para a **IDEALIZA Contabilidade** (David Hilário Dodou), com foco em segurança jurídica, planejamento tributário, gestão financeira e conversão via WhatsApp.

---

## 🚀 Sobre o Projeto

A Landing Page foi estruturada com design premium, tipografia refinada e arquitetura pensada para empresários que buscam redução de custos tributários e assessoria contábil estratégica.

### Principais Seções:
- **Hero:** Proposta de valor clara com chamada para ação (CTA) direta.
- **Autoridade e Métricas:** Números de impacto (+R$ 8 milhões em economia, décadas de mercado em Fortaleza e Juazeiro do Norte).
- **Serviços:** BPO Financeiro, Planejamento Tributário, Abertura/Regularização e Consultoria Empresarial.
- **Processo:** Como funciona o onboarding e fluxo de atendimento.
- **Migração Descomplicada:** Seção dedicada para quem já possui contador e deseja migrar sem atrito.
- **Sobre o Fundador:** Trajetória, formação e liderança de David Hilário Dodou.
- **FAQ e Rodapé:** Esclarecimento de dúvidas frequentes e links de contato.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Marcação estruturada, acessível e otimizada para SEO.
- **CSS3 / Estilos Utilitários:** Layout flexível, responsivo e transições suaves (`style.css`).
- **JavaScript Vanilla:** Lógica interativa, modais, máscaras e animações (`script.js`).
- **Iconify:** Ícones duotone solares de alta definição.
- **Google Fonts:** Tipografia com as famílias *Outfit* e *Playfair Display*.

## 💻 Como Executar Localmente

Como se trata de uma aplicação estática (HTML/CSS/JS), nenhuma instalação de dependências ou build é necessária:

1. Clone o repositório:
   ```bash
   git clone https://github.com/ismaelmatias7622-source/lp-david.git
   ```
2. Abra a pasta do projeto e dê um duplo clique no arquivo `index.html`, ou utilize extensões como **Live Server** no VS Code para servir localmente.
